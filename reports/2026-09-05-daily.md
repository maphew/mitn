  `.worktrees/trilium/pr-NNNNN`.

  fails; prefix PATH with `/c/Users/Matt/AppData/Roaming/npm` after
  `npm i -g pnpm@11.25.0`.

  `-c credential.helper= -c 'credential.helper=!gh auth git-credential'`.

  `-o`; capture stdout instead.
- The headless repro harness works on Windows with Node 25.8; stop the
  server by port with `Get-NetTCPConnection`.
