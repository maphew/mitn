  (tagged the same day), run from source. Includes the mention-plugin
  rewrite `52d17ef27a` and our anchor fix `5c8ac043ce` (PR 11063).

  plus scratch `TRILIUM_DATA_DIR` seeded from the fixture `document.db`,

  the server aborts with "Public directory is missing" (assets.ts picks
  the vite dev middleware only in development).
- Headless Chromium via the worktree's playwright-core. On a bare WSL
  host, chromium needs `libasound.so.2`; extracted from the `libasound2`
  deb into a scratch dir and passed via `LD_LIBRARY_PATH`, no root needed.

## Protocol

Same as the 2026-08-17 repro that confirmed the race pre-fix
(`repro/repro10663b.js`, adapted as `repro/repro10663-retest.js`): clear
the note and let saves settle, inject 2000-4000 ms latency (CDP
`Network.emulateNetworkConditions`), type `AAA @Themes`, pick the
froca-cold hidden help note by keyboard (`glob.froca.notes[id]` verified
undefined before the pick), immediately type ` BBB CCC DDD` through the
resolution window, then count tokens in the final text.

## Results

Five runs: one cold at 2000 ms, one warm and three cold at 4000 ms (cold
runs on a pristine fixture db with a fresh server each,
`t10663-cycle.sh`). Four runs finished with the reference link at the
pick position and final text `AAA Themes BBB CCC DDD`, every token
exactly once. On the same protocol, pre-fix main `964e23ec56` reliably
produced the misplaced or lost insertion.

One run (second overall) ended with the pick never applied: `AAA @Themes`
remained as plain text and the trailing ` BBB CCC DDD` went somewhere
other than the editor. It did not recur across three later cold cycles,
so we read it as the Enter keypress racing the balloon-list refresh in
the harness, not an application bug. Even that run duplicated nothing.

## Verdict

Duplication does not reproduce on `86a9715b09` under the conditions that
reliably exercised the underlying race before the rewrite. Android IME
amplification remains untested here (no device), and eliandoran already
could not reproduce on the mobile app. Gated reply:
`comment-issue10663-retest.md`.
